# PACTO · Estúdio de carrosséis

Instaladores do app do curso **Carrosséis Que Vendem**. O código do aplicativo não fica aqui.

| Sistema | Baixar |
|---|---|
| Windows 10 ou 11 | [PACTO-Windows.exe](https://github.com/Mathpcastro/pacto-releases/releases/latest/download/PACTO-Windows.exe) |
| Mac com Apple Silicon (M1 ou mais novo) | [PACTO-Mac-AppleSilicon.dmg](https://github.com/Mathpcastro/pacto-releases/releases/latest/download/PACTO-Mac-AppleSilicon.dmg) |
| Mac com processador Intel | [PACTO-Mac-Intel.dmg](https://github.com/Mathpcastro/pacto-releases/releases/latest/download/PACTO-Mac-Intel.dmg) |

Os links sempre baixam a versão mais nova.

## Windows
1. Abra o arquivo baixado.
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações** → **Executar assim mesmo**.
3. Siga o instalador. As próximas versões chegam sozinhas: o app baixa em segundo plano e instala quando você fechar.

## Mac (macOS 12 ou mais novo)
Para saber qual baixar: menu  → **Sobre Este Mac**. "Chip Apple M…" = Apple Silicon; "Processador Intel" = Intel.

1. Abra o .dmg e arraste o PACTO para **Aplicativos**.
2. Abra o PACTO. Se o Mac avisar que não pode verificar o desenvolvedor, clique em **OK**.
3. Em **Ajustes do Sistema → Privacidade e Segurança**, clique em **Abrir Mesmo Assim** no aviso do PACTO.
4. Se aparecer que o app "está danificado", abra o Terminal, cole `xattr -cr /Applications/PACTO.app` e abra de novo.
